# TripMate-AI---A-Multi-Agent-Travel-Planner

## how to run

1 create virtual environment
```bash 
conda create -n travel python=3.11 -y
```

2. activate the environment
```bash 
conda activate travel
```

install the req
```bash
pip install -r requirements.txt
```
